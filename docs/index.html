How it works

四步，构建你的私人防护圈

从录入到保护，一切都在你的设备上静默完成。

录入机主

正对摄像头采集 20 张人脸样本，让屏安符记住“自己人”。

持续识别

摄像头实时检测画面中的人脸，判断是机主、陌生人，还是没人。

触发判断

结合触发规则（陌生人靠近 / 机主离开）与距离，计算保护强度。

平滑保护

覆盖层从透明平滑淡入，模糊或遮挡屏幕；情况解除后自然淡出。

Two methods

两种手段，按需组合

各自独立开关，各自选择触发原因，既可单用也可叠加。

保护手段 一

窗口模糊 / 遮挡覆盖

在全屏铺一层模糊与暗色遮罩，让旁人看不清屏幕内容，强度随风险平滑变化。

  • 简易模式：暗色覆盖 + 毛玻璃质感，无需截屏权限
  • 真实模糊：MSS 抓屏 + 高斯模糊，实时模糊桌面
  • 可调触发距离、最大暗度、模糊强度
  • 防闪烁：渐进淡入 + 连续强度
保护手段 二 · 仅 Windows

自动置顶指定程序

触发保护时，把指定程序窗口自动切到最上层；解除后还原它原本的置顶状态。

  • 点选当前窗口，自动记录进程名
  • 手动填写进程名 / 窗口标题关键字
  • 规则匹配不区分大小写
  • 与模糊覆盖完全解耦，可单独工作
